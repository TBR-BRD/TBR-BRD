## Hi, I'm Thoralf 👋

Maker from Germany. I build practical things around **Home Assistant**, **solar power**, **internet radio** and small **ESP32 / Raspberry Pi** gadgets – and publish them here so others can copy, adapt and improve them.

🌐 Project overview: **[lets-make.de](https://www.lets-make.de)**

### 📻 Radio & music
| Project | What it does |
|---|---|
| [onradio-cover-bridge](https://github.com/TBR-BRD/onradio-cover-bridge) | Raspberry Pi radio & cover display, plays on Sonos, Google Cast, AirPlay |
| [googletv-musicplayer](https://github.com/TBR-BRD/googletv-musicplayer) | The same experience as a standalone Google TV app |
| [cover-music-player](https://github.com/TBR-BRD/cover-music-player) | Chrome extension with live album covers |
| [bbuzzcanvas-cover-kiosk](https://github.com/TBR-BRD/bbuzzcanvas-cover-kiosk) | Turns a BBuzzCanvas frame into a cover display |
| [radiostations](https://github.com/TBR-BRD/radiostations) | Shared station catalog for the apps above |
